AstraDraw: from references to editable figures

Filed under Project notes · Last updated on October 8, 2026

A research figure rarely ends with its first draft. Labels move, arrows change, and the layout needs to work at paper size. Keeping these parts editable makes room for the next revision.

Start with references

AstraDraw uses a paper to understand the method, and reference figures to understand the visual style. Put the references in a PowerPoint file and note what you want to borrow: a layout, a color palette, an arrow, or a legend.

You can give Astra the local file paths. The repository also includes a shared reference library and example assets if you do not have your own collection yet.

An editable figure

After choosing a direction, the workflow produces a PowerPoint file and a preview. Text, arrows, and layout can then be adjusted in the editable version. This is one of the examples included in the repository.

Check it at paper size

A figure that looks clear when enlarged may be hard to read on the page. Check the labels, arrow directions, and spacing again at the size you plan to use.

Revise one part at a time

For a small change, point to the object that needs work. Select it in the PPT, or mark it in a screenshot. The repository includes an example where a single label moves while the rest of the figure stays in place.

“Move the label in the top-right corner down a little. Keep everything else as it is.”

See the before-and-after example ↗

Try AstraDraw

The repository contains the setup instructions, reference materials, sample figures, and editable files. Start with your paper and a few references, then revise the result where it needs work.
